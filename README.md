# 🚀 **Project Showcase: Image Steganography Using C**
This project implements a steganography tool that allows users to hide secret messages within BMP image files.  The tool provides two main functionalities in main: encoding and decoding. 

I'm excited to share my Image Steganography project, developed using C programming and the Least Significant Bit (LSB) technique.

🔹 **Project Overview:**
This project hides secret text messages inside BMP images and extracts them when required, while maintaining the visual appearance of the image.

✨ **Key Features:**
* Encode secret messages into BMP images.
* Decode and retrieve hidden messages.
* Validate image capacity before encoding.
* Handle image and text files using C.

🛠️ **Technologies:**
C Programming, File Handling, Bit Manipulation, and LSB Steganography.

📚 This project helped me gain practical experience in image processing, binary data manipulation, and encoding and decoding techniques.
